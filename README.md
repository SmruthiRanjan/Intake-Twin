# IntakeTwin 📊💧

 IntakeTwin is a modern, visually appealing web application designed to help users easily track their daily calorie consumption and water intake. It provides a clear dashboard summary, allows for detailed entry logging, visualizes historical data, and offers data export capabilities, all wrapped in a sleek 'glassmorphism' theme.

## Features ✨

*   **Calorie Tracking:** Log food items with calorie counts and meal types.
*   **Water Tracking:** Log water intake amounts in milliliters (ml).
*   **Daily Summaries:** Visual progress for calories and total water display.
*   **Entry Lists:** View detailed lists of food and water consumed today.
*   **Item Removal:** Easily delete incorrect food or water entries.
*   **Historical Data:** View recent calorie history and a combined chart for calorie/water trends.
*   **Data Export:** Export daily summaries and detailed entries to Excel (.xlsx) and PDF.
*   **Theme Switching:** Toggle between Light and Dark themes.
*   **Persistence:** Uses Local Storage to save data in your browser.
*   **Responsive Design:** Adapts layout for different screen sizes.

## Technologies Used 🛠️

*   **Core:** HTML5, CSS3, JavaScript (ES6+)
*   **Styling:** CSS Variables, Glassmorphism, Flexbox & Grid, Media Queries
*   **Functionality:** DOM Manipulation, Local Storage API
*   **Libraries:** Chart.js, jsPDF & jsPDF-AutoTable, SheetJS (xlsx)

## Getting Started 🚀

**To run this application, simply open the `index.html` file in your web browser.**

**Steps:**

1.  **Download or Clone:** Get the project files onto your computer. If you cloned using Git:
    ```bash
    git clone https://github.com/your-github-username/IntakeGlass.git
    cd IntakeGlass
    ```
    *(Replace `your-github-username/IntakeGlass.git` with your actual repository URL)*
    If you downloaded a ZIP, extract it to a folder.

2.  **Locate the Files:** Find the folder where you saved or extracted the project files (`index.html`, `style.css`, `script.js`).

3.  **Open `index.html`:** Double-click the `index.html` file. It should open directly in your default web browser.

**Data Saving:**

*   The application automatically saves your calorie entries, water entries, theme preference, and calorie goal using your browser's **Local Storage**. This data stays on your computer within that specific browser.
*   To save this README file itself, ensure you save the content as `README.md` in the main project folder.
